============================================================
 BUILD SHIELD - WINDOWS SETUP COMMANDS
 Run all commands in the VS Code terminal (PowerShell),
 from the Build Shield project root folder.
============================================================

------------------------------------------------------------
 0. OPEN THE PROJECT
------------------------------------------------------------
cd "path\to\Build Shield"
code .

------------------------------------------------------------
 1. POWERSHELL BYPASS (CURRENT USER ONLY)
------------------------------------------------------------
Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy Bypass -Force

(Optional: only for this terminal session, resets when closed)
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass -Force

------------------------------------------------------------
 2. RUN THE AUTOMATED SETUP SCRIPT
------------------------------------------------------------
.\setup.ps1

(One-line alternative that skips the policy step)
powershell -ExecutionPolicy Bypass -File .\setup.ps1

------------------------------------------------------------
 3. VIRTUAL ENVIRONMENT (.venv) - MANUAL COMMANDS
------------------------------------------------------------
Create:
python -m venv .venv

Activate:
.\.venv\Scripts\Activate.ps1

Deactivate:
deactivate

------------------------------------------------------------
 4. PIP INSTALL
------------------------------------------------------------
python -m pip install --upgrade pip
pip install -r requirements.txt

Save installed packages to requirements.txt:
pip freeze > requirements.txt

------------------------------------------------------------
 5. NPM AND VITE
------------------------------------------------------------
cd frontend
npm install
npm install --save-dev vite

Create a new Vite app (only if you do not have one yet):
npm create vite@latest frontend

Run the dev server:
npm run dev

Build for production:
npm run build

------------------------------------------------------------
 6. DAILY START (AFTER FIRST SETUP)
------------------------------------------------------------
.\.venv\Scripts\Activate.ps1
cd frontend
npm run dev

------------------------------------------------------------
 TROUBLESHOOTING
------------------------------------------------------------
- "running scripts is disabled": run step 1 again.
- "python is not recognized": install Python 3.12 from python.org
  (tick "Add Python to PATH") or run: winget install Python.Python.3.12
- "npm is not recognized": install Node LTS or run:
  winget install OpenJS.NodeJS.LTS, then restart VS Code.
- Check the policy: Get-ExecutionPolicy -List
